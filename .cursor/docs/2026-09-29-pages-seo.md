GitHub Pages는 HTTP 302를 보내지 못한다. `Astro.redirect('/ko/')`는 2초 meta refresh HTML만 만들어서 루트가 멈춰 보였다. `src/pages/index.astro`를 `location.replace`와 `refresh` 0초, 클릭 가능한 링크로 바꿨다.

## 읽는 순서

1. `.github/workflows/deploy.yml` — `main`에 푸시하면 `withastro/action`이 `npm run build`를 돌리고 Pages에 올린다. 이 저장소는 유저 사이트라 `base`가 없다.

2. `astro.config.mjs` — `site`가 `https://khc1104.github.io`이고, sitemap 통합이 빌드 때 XML을 만든다.

3. `src/layouts/BaseLayout.astro` — 모든 페이지의 title·description·canonical·한/일 hreflang·og 태그가 여기 있다. `x-default`는 `/ko/`다.

4. `src/pages/[lang]/index.astro` — 홈 description은 `heroBody`, og:image는 있으면 대표작 스크린샷이다.

5. `public/robots.txt` — 크롤러에게 sitemap 주소를 알려 준다.

6. `src/pages/404.astro` — 없는 주소용 HTML이다. `/ko/`와 `/ja/` 링크만 둔다.
