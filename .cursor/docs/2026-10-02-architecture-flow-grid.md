## 한 일
- 데스크톱(md 이상)에서 흐름 그림의 가로 스크롤을 없애고 3열 격자로 줄바꿈했다.
- Insulin Note "설계와 기술 선택"(5단계)은 3·2, KanjiMate OCR 파이프라인(7단계)은 3·3·1로 보인다.
- `→`는 같은 줄 카드 사이 간격에만 두고, 줄 끝 카드와 마지막 카드 뒤에는 표시하지 않는다.
- 모바일은 기존처럼 세로로 쌓이고 카드 사이마다 `↓`가 보인다.

## 변경 파일
- `src/components/mdx/ArchitectureFlow.astro` — `md:grid md:grid-cols-3`, 화살표 절대 배치, `index % 3 === 2`면 `md:hidden`

## 확인
- `npm run build` 통과 (20페이지).
- 브라우저 측정: ko/ja Insulin Note 3·2, ko KanjiMate 3·3·1, `ol` 가로 스크롤 없음, 화살표는 24px 간격 안(카드와 겹치지 않음).
- 390px: 세로 스택, 모든 카드 사이 `↓`, 문서 가로 넘침 없음.
- HIG: 화살표는 `aria-hidden`, 목록 의미(`ol`) 유지, 새 상호작용·움직임 없음, 색 대비 변경 없음.
- 리스크: 단계가 4개면 3·1로 보인다. 현재 사용처는 5·7단계뿐이다.
