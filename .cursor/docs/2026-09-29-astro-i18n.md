# Astro 초기화와 ko/ja 뼈대

- 날짜: 2026-09-29
- Phase: 1
- 상태: 완료

## 한 일

- 기존 Git/`.cursor`를 유지한 채 Astro 정적 프로젝트를 올렸다. CLI 최신은 Astro 7 + Tailwind 4 + MDX다.
- `/`는 `/ko/`로 가고, `/ko/`와 `/ja/`는 같은 레이아웃·섹션 껍데기를 쓴다. 헤더에서 언어를 바꾼다.

## 변경 파일

- `package.json`, `astro.config.mjs`, `tsconfig.json` — 사이트 URL, i18n, 정적 빌드
- `src/pages/index.astro` — `/` → `/ko/`
- `src/pages/[lang]/index.astro` — ko/ja 홈
- `src/layouts/BaseLayout.astro` — `html lang`, 헤더/푸터
- `src/components/Header.astro`, `src/components/Footer.astro`
- `src/i18n/ui.ts`, `src/i18n/utils.ts` — 플레이스홀더 문구
- `src/styles/global.css` — Tailwind
- `README.md`, `.gitignore`

## 확인

- `npx astro build` 성공. `dist/ko/index.html`, `dist/ja/index.html`, 루트는 `/ko/` 리다이렉트. `base` 경로 없음.
- 브라우저 preview: `/` → `/ko/`, 日本語 → `/ja/`, 한국어 → `/ko/`. `html lang`은 ja/ko. 390px에서 헤더 넘침 없음.

## 읽는 순서

1. `astro.config.mjs` — 사이트 주소와 언어 규칙을 정한다. 여기서 `ko`/`ja` prefix와 `site`가 정해지면 아래 페이지 URL이 따라간다.

2. `src/pages/index.astro` — `/`를 연 사람이 `/ko/`로 가게 한다. Astro에서 `src/pages/` 아래 파일이 곧 주소다.

3. `src/pages/[lang]/index.astro` — `[lang]`은 URL의 언어 자리(`ko` 또는 `ja`)다. 홈의 Hero~Contact 껍데기를 여기서 조립한다.

4. `src/layouts/BaseLayout.astro` — 모든 홈이 공유하는 HTML 뼈대다. `<html lang>`과 헤더/푸터를 끼운다.

5. `src/components/Header.astro` — 사이트 이름, 내비, 언어 링크를 그린다. `getRelativeLocaleUrl`로 `/ko/`와 `/ja/`를 오간다.

6. `src/i18n/ui.ts` — 화면에 보이는 짧은 문구 사전이다. 한국어/일본어 키가 여기 있다.

3. 헤더의 「日本語」를 바꾸려면 `Header.astro`와 `ui.ts` 중 어디를 고치는가?
