# Astro 초기화와 ko/ja 뼈대

- 날짜: 2026-09-29
- Phase: 1
- 상태: 완료

## 한 일

- 기존 Git/`.cursor`를 유지한 채 Astro 정적 프로젝트를 올렸다. CLI 최신은 Astro 7 + Tailwind 4 + MDX다.
- `/`는 `/ko/`로 가고, `/ko/`와 `/ja/`는 같은 레이아웃·섹션 껍데기를 쓴다. 헤더에서 언어를 바꾼다.

## 변경 파일

- `package.json`, `astro.config.mjs`, `tsconfig.json` — 사이트 URL, i18n, 정적 빌드
- `src/pages/index.astro` — `/` → `/ko/`
- `src/pages/[lang]/index.astro` — ko/ja 홈
- `src/layouts/BaseLayout.astro` — `html lang`, 헤더/푸터
- `src/components/Header.astro`, `src/components/Footer.astro`
- `src/i18n/ui.ts`, `src/i18n/utils.ts` — 플레이스홀더 문구
- `src/styles/global.css` — Tailwind
- `README.md`, `.gitignore`

## 확인

- `npx astro build` 성공. `dist/ko/index.html`, `dist/ja/index.html`, 루트는 `/ko/` 리다이렉트. `base` 경로 없음.
- 브라우저 preview: `/` → `/ko/`, 日本語 → `/ja/`, 한국어 → `/ko/`. `html lang`은 ja/ko. 390px에서 헤더 넘침 없음.
